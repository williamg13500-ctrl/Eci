From this directory, install dependencies using Bun (`bun install`) and start the development server with `bun run dev`.

## Hatchable import

Import the `asset-huggers/` directory as a separate Hatchable project/root. The root-level Hatchable application and its manifest belong to the existing Edmond Clinton Inc. project; do not import the repository root when creating the Asset Huggers app.
